# vattenfall-week9-capstone-EmilyImunde
Databricks lakehouse capstone for a Vattenfall-inspired energy platform

# Project Theme:
The company vattenfall needs a governed data platform that can combine several operational domains. 

# Data Source:
The four data sources that will be ingested into this data pipeline shall include: 
1. Energy market prices
2. Weather observations
3. Grid events
4. Reference data

 # Project architecture: 
 Landing, bronze, silver, business logic, gold, and dashboards.

 # Engineering methods: 
 Auto Loader, Delta tables, PySpark transformations, SQL, validation, and Unity Catalog.

 # Output: 
 Governed business-ready analytics tables and dashboard-ready views.
