
# 1_project_overview
This project concerns building a Databricks lakehouse capstone for a Vattenfall-inspired energy platform. 
The four main stages include:

- Ingesting market price, weather, grid event, and reference files into bronze.
- Cleaning and standardizing the data into silver using modular PySpark logic.
- Creating business logic and gold reporting outputs for energy operations analysis.
- Using Unity Catalog structure, validation checks, and dashboard-ready tables/views
